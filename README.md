# Mirror-Invariant Handwritten Digit Recognition

## Overview

This project explores mirror-invariant feature learning for handwritten digit recognition using the MNIST dataset. It implements a Convolutional Neural Network (CNN) that encourages consistent feature representations between original images and their horizontally mirrored versions.

## Methodology

The project compares a baseline CNN with a mirror-invariant CNN. The proposed approach uses a feature-consistency loss to encourage the model to learn similar representations for original and mirrored images while maintaining accurate digit classification.

## Technologies Used

The project is implemented in Python using TensorFlow and Keras for model development and training, NumPy for numerical operations, Matplotlib for visualization, and Scikit-learn for evaluation.

## Future Improvements

Future work may explore alternative CNN architectures, additional data augmentation techniques, and evaluation under different image transformations to further investigate the model's robustness.
